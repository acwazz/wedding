# Memory Bank

Indexed docs keeping project context across sessions. Read `activeContext.md` + `progress.md` first, then others as needed.

- `projectbrief.md` — core requirements, scope
- `productContext.md` — why project exists, audience
- `systemPatterns.md` — architecture, code conventions
- `techContext.md` — stack, tooling, commands
- `activeContext.md` — current state, next steps
- `progress.md` — what done, what left, decisions

Update `activeContext.md` and `progress.md` at end of each work session.
